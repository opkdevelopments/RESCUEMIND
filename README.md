# 🌍 About The Project

RescueMind AI is a cinematic AI-assisted disaster response platform designed to help emergency rescue teams make intelligent routing decisions during rapidly changing disaster conditions.

The system dynamically analyzes hazard zones, blocked roads, civilian locations, and disaster escalation to generate optimized rescue paths in real time.

Built specifically for emergency coordination scenarios where every second matters.

---

# ✨ Core Features

## 🗺️ Live Disaster Intelligence Map

- Real-time hazard visualization
- Flood and danger zone detection
- Rescue unit tracking
- Civilian cluster identification
- Shelter and evacuation mapping

---

## 🧠 AI Rescue Route Optimization

The AI engine calculates:

- Safest route
- Fastest route

- Dynamic rerouting during road failures

# 🚀 Getting Started

## 1️⃣ Clone Repository

```bash
git clone https://github.com/opkdevelopments/RESCUEMIND.git
```

---

# 📦 Frontend Setup

## Navigate to Frontend

```bash
cd frontend
```

---

## Install Dependencies

```bash
npm install
```

---

## Run Frontend

```bash
npm run dev
```

Frontend runs on:

```text
http://localhost:3000
```

---

# ⚙️ Backend Setup

## Navigate to Backend

```bash
cd backend
```

---

## Create Virtual Environment (Recommended)

### Windows

```bash
python -m venv venv
venv\Scripts\activate
```

### Linux / macOS

```bash
python3 -m venv venv
source venv/bin/activate
```

---

## Install Python Dependencies

```bash
pip install -r requirements.txt
```

---

## Start Backend Server

```bash
uvicorn main:app --reload
```

Backend runs on:

```text
http://127.0.0.1:8000
```
